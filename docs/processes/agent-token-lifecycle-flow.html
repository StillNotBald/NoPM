Fastest path

the shortest governed agent connection
  1. Mint a tokenadmin/manager · scopes chosen up front
  2. Agent calls with BearerMCP, CLI, or REST
  3. Scope checked403 if missing, named exactly
  4. Executes + auditedone row, channel + actor stamped
  5. Revoke anytimenext call is 401, no delay
The ceiling is machine-checked: an approve/admin scope is never in the assistant's or a token's default reach.

Channel (ui/api/cli/mcp/assistant) is provenance only, stamped on every audit row — it is never itself an authorization input; scope is the only thing the guard checks.

Why it holds

  • Minting is admin/manager-only session action — a token can never mint itself a sibling token.
  • A missing scope, e.g. task:delete:request, fails closed with 403 naming exactly what was missing.
  • Revoke is a boolean flip, not a queued job — the very next call already sees it.
