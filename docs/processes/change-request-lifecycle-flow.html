A decided CR is a governed fact for the record — not an execution trigger.

Two confirmed absences, shown honestly rather than assumed: a locked project does NOT block raising or deciding a change request (only tasks, milestones, and dependencies are lock-guarded), and an approved change request has no automatic effect — it is a governed record, not an executor, in v1.
