## REQUIREMENTS.md bullets

- **R-137** Test and UAT evidence on a change request (audit gap M4). A document can be attached to one change request as test result, UAT sign-off, deploy record, screenshot or other evidence, with a result, a tester and a date. Acceptance: (a) migration 0094 adds nullable `documents.change_request_id` (FK to change_requests, ON DELETE SET NULL, partial index), `evidence_type` (`test_result|uat_signoff|deploy_record|screenshot|other`), `evidence_result` (`pass|fail|partial|n/a`), `tested_by_label`, `tested_at`, `evidence_note`; CHECKs on both value lists and "a result needs a type"; no backfill, no trigger touched; a document is evidence only when `change_request_id` is set; (b) `POST /api/documents` and `PATCH /api/documents/:id` accept, validate and return the fields; the change request must be in the same workspace AND the same project as the document (422 `invalid_reference` / `evidence_link_invalid`), evidence fields without a change request are refused (422 `evidence_needs_change_request`), unlinking clears them, and tester and time default to the caller and now when evidence is first recorded; the one existing audit row carries `change_request_id` in `after`; `GET /api/documents` filters by `change_request_id`; (c) `GET /api/change-requests/:id/evidence` (scope `document:read`, workspace-filtered, 404 for another workspace's request) lists the linked documents, latest test first; (d) the change request detail shows an Evidence panel (type and result badges, tester, date, link to the document, "Attach evidence" opening the document form pre-filled with the request), stacked rows at phone width; the document form gains an Evidence section and the document viewer shows the evidence rows when a request is linked. (e) a trigger clears the five evidence columns whenever `change_request_id` becomes NULL (API unlink or the request being deleted). Migration 0094 must be applied BEFORE the build serves traffic: document create always writes the new keys, so without it every document create fails, and the evidence route names the columns. — **DONE** (migration 0094, documents routes, evidence route, `evidence-panel.tsx`, document form and viewer, tests)
