**Why approval uses existing verbs.** I did not add `<entity>:delete:approve` scopes. They would have to be in `PRIVILEGED_SCOPES`, which `scopes.test.ts` and `tokens.test.ts` pin exactly, and an unregistered name would let a `program:*` wildcard token pass the scope check. The program uses `project:delete:approve`, the other four use `task:delete:approve`. If you want dedicated approve scopes, that is a four-line change in `scopes.ts` plus the two pinned tests, then edit the two maps in `deletion-dispatch.ts`.
