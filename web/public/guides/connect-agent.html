N NoPM Agent-Connect Guide

Connecting an AI agent to NoPM

Two ways to hand NoPM to a real agent: a remote connector for Claude on the web, and a local process for Claude Desktop or Claude Code. Both routes are the same governed REST API behind a scoped token; nothing about the agent surface is a special case.

The line for the room

NoPM ships no model. The agent brings its own intelligence and calls the same REST API a human console does, through a permission-scoped Bearer token. Every write still lands one immutable audit row, and deleting a project or task still needs a second, different approver. The agent cannot route around governance — it operates inside it.

The claude.ai run is the sharper proof: a foreign, general-purpose agent (not code we wrote for the occasion) reasons over real project data and hits the same guardrails a human would.

A

claude.ai — remote connector

For the live pitch: pull up claude.ai in a browser and ask it to operate NoPM in front of the room.

  1. Mint a scoped token NoPM → Settings → API Tokens → name it, e.g. investor-demo, and mint. Read scopes are enough for a walkthrough; the token is shown once.
  2. Add the connector claude.ai → Settings → Connectors → Add → Add custom connector. Name NoPM, URL https://stillnotbald.com/api/mcp.
  3. Set authentication to "None," then add a header This isn't unauthenticated: "None" tells claude.ai to skip its own OAuth handshake, since NoPM authenticates via a plain API key instead. Under Request headers: name authorization, value Bearer <token>. Save, then Connect.
Live in the room

Type: "Use the NoPM connector to list my projects."

Claude asks permission to call List projects. Approve it live. That prompt is a beat: the room watches an external agent get stopped and asked before it touches anything.

The response reads real portfolio data and volunteers an insight worth having: which "green" projects are actually just downstream of an amber one that hasn't broken yet. Nobody scripted that line; it's the model reasoning over governed data it was scoped to read.

If it 401s

claude.ai's header field can mangle a pasted value on a slow paste. Revoke the token in NoPM, mint a fresh one, then remove and re-add the connector. There's no edit path for an existing connector's header — only remove and re-add.

B

Claude Desktop / Claude Code — local process

For the technical deep-dive, or as the fallback when a venue's Wi-Fi makes a live web demo risky.

  1. Mint a token Same as above: NoPM → Settings → API Tokens → New Token.
  2. Point the client at it Claude Code: this repo already ships .mcp.json. Set NOPM_TOKEN in your shell and reopen the repo. Claude Desktop: add the block below to claude_desktop_config.json.
    claude_desktop_config.json 
    {
  "mcpServers": {
    "nopm": {
      "command": "node",
      "args": ["/absolute/path/to/NoPM/web/mcp/server.mjs"],
      "env": {
        "NOPM_API_URL": "https://stillnotbald.com",
        "NOPM_TOKEN": "npm_your_token_here"
      }
    }
  }
}
  3. Restart, then ask Restart the client. 24 tools appear: projects, tasks, risks, issues, budget, clashes, resources, audit. Same prompt as Part A works identically.
